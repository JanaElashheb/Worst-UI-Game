**Worst UI Game**
A Python game project designed around intentionally awkward and challenging user interface elements.

**About the Project**
This project explores how user interface design can affect the way a player interacts with a game. The interface was intentionally designed to be inconvenient and difficult to use, turning poor UI design into part of the gameplay experience.
The project was also an opportunity to practice organizing a Python game into multiple classes and files.

**Features**
- Interactive game built with Python
- Intentionally unconventional user interface
- Multiple classes used to organize the game
- Player interaction and game logic
- Separate files for game functionality and classes

**Technologies Used**
- Python
- Project Files
- main.py — Main program and game execution
- classes.py — Classes used by the game
- .gitignore — Prevents unnecessary system files from being uploaded

**Purpose**
The purpose of this project was to experiment with Python game development while exploring how interface design can influence usability and the player’s experience.
